# cart_pricing

An offline Elixir application skeleton that depends on the Ash Framework.

* All dependencies are already fetched and compiled for both the `dev` and
  `test` Mix environments; the machine has no network access.
* The sales domain, its resources and its derived pricing fields are not
  implemented yet.

Useful commands:

```
mix compile
MIX_ENV=test mix compile
mix test
```
