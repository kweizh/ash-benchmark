# Cascading Soft-Delete, Global Read Scoping and Archive Recovery (Ash Framework v3) ## Background `/home/user/forum` holds a Mix project (OTP app `:forum`) for a discussion-forum backend built on the Ash Framework v3 (`ash 3.31.0`). Content is three levels deep: a post owns comments, and a comment owns reactions. Deleting content in this product is never destructive: removed content stays in storage, stays invisible to ordinary readers, can be inspected by an administrator, and can be recovered later. Recovery has to be *precise* — undoing a deletion must bring back exactly what that deletion removed and must not resurrect content that had already been deleted by an earlier, unrelated operation. The project currently contains only the domain shell and the project configuration. a comment's reactions) are archived together as one generation: all of them end up with the *same* non-`nil` `archived_at` value and the *same* non-`nil` `archive_batch_id` value. * Descendants that were already archived before the call keep their existing `archived_at` and `archive_batch_id` values byte-for-byte. * Two separate archive operations must never produce the same `archive_batch_id`. ### Restore semantics — action `:restore` * On a record that is not archived the call succeeds and changes nothing, anywhere. * On an archived record: the target's `archived_at` and `archive_batch_id` both become `nil`, and every descendant whose `archive_batch_id` equals the target's `archive_batch_id` as it was immediately before the call is restored the same way (`archived_at` and `archive_batch_id` set to `nil`), recursively. * Descendants carrying a different `archive_batch_id` are left exactly as they were. * `:restore` never affects ancestors of the target. ### Purge semantics — action `:purge` * Invoked on a record whose `archived_at` is `nil`, the action must fail and change nothing: the result must be `{:error, %Ash.Error.Invalid{errors: errors}}` where at least one element of `errors` is an `%Ash.Error.Changes.InvalidChanges{}` whose `:fields` is `[:archived_at]` and whose `:message` is exactly `"must be archived before it can be purged"`. * Invoked on an archived record, the record and every one of its descendants are permanently and irrecoverably removed from storage. ### Read scoping * `:read` returns only records whose `archived_at` is `nil`.
